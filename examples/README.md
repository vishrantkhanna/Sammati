# Examples

| Folder | Shows |
| --- | --- |
| `html` | The one-line widget, and a hand-built form that calls the API |
| `react` | A React component that loads the widget |
| `wordpress` | A small plugin that adds a `[sammati form="..."]` shortcode |
| `webhook-receiver` | Receivers in Node and Python that check the signature |

Replace `https://consent.example.com` with your own Sammati address.
