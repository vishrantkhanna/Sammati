# Changelog

## 0.1.0

First release.

- Purposes, versioned notices in several languages, and consent forms.
- Hosted form page, one-line website widget and a manage page where people
  see and withdraw their consent. English and Hindi built in.
- Append-only, hash-chained consent records, with a verify command and CSV
  export. Identifiers stored only as keyed fingerprints.
- Admin screens: first-run setup, sign-in with optional two-step codes,
  purposes, notices, forms, records, integrations and settings.
- REST API, API keys and signed webhooks with retries.
- Docker image, Compose file, Caddy, Nginx and systemd examples.
- Guides and examples for HTML, React and WordPress.
- Upload your own logo. It leads the admin top bar, forms and manage
  pages, with a small "Powered by Sammati" beside or below it.
- The Sammati mark and wordmark.
- The sign-in page shows no hints about the installation.
